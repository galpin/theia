# Catppuccin Themes for Theia

Minimal Theia extension that adds [Catppuccin](https://github.com/catppuccin) color themes.

## Themes Included

- **Catppuccin Mocha** - Warm, cozy dark theme (most popular variant)
- **Catppuccin Latte** - Clean, elegant light theme

## Features

- Zero npm dependencies (beyond Theia core)
- Official Catppuccin color palettes
- Full syntax highlighting support
- Complete UI theming for all Theia components
- Terminal ANSI colors
- Git decoration colors

## Usage

Select themes from: **Settings → Appearance → Color Theme**
